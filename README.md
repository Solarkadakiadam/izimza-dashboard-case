# izimza-dashboard-case

Vue 3 dashboard application.

## What's Built

- Login/Register pages
- Dashboard page
- Form validation (VeeValidate + Yup)
- Nested routes
- Responsive design
- E2E tests (Playwright)
- GitHub Actions CI

## Tech Stack

Vue 3, TypeScript, Vite, PrimeVue, Pinia, Vue Router

## Run

```sh
npm install
npm run dev
```

## Test

```sh
npx playwright install
npm run test:e2e
```
